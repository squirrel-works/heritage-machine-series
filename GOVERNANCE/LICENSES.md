# Licenses

## Purpose

Record the licensing approach for repository content.

## Policy

Original technical writing, original CAD, original photographs, and source
code should be released under the project's chosen open license. Imported
third-party material must be compatible with that license and documented
individually.

## Guidance

- Prefer a small number of clearly documented licenses.
- Record the license for each source, image, and artifact.
- Do not assume a source is reusable without checking the terms.
- Separate the license for your work from the license for source material.

## Notes

If the repository contains multiple license regimes, they should be listed in
a top-level license register and referenced in metadata.
