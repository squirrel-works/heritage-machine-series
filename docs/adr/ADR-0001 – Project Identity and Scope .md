# ADR-0001 – Project Identity and Scope  
  
## Title  

Adopt “The Heritage Machine Series” as the project identity and treat each machine volume as an engineering reference, not a casual manual.  
  
## Context  

The initial project text defines a long-term documentation effort for vintage machinery, with the Craftsman 113.241680 as the first volume, and explicitly contrasts an engineering reference with a restoration blog or simple owner’s manual.  
  
## Decision  

- The overall project will be named **The Heritage Machine Series** with the subtitle “Engineering Reference Library for Classic Machinery”.  
- Each volume will be structured as an engineering reference similar in philosophy to *Machinery’s Handbook*, not a narrative book or basic owner’s manual.  
- The first volume will focus on the Craftsman Model 113.241680 table saw.  
  
## Consequences  

- Content must prioritize measured data, verified specifications, standards, and engineering analysis over anecdotal tips.  
- Structure, tone, and rigor must be consistent across machines; the series is reusable beyond the 113.241680.  
- Readers will expect durable, citation-backed technical information, so the project must invest in verification, provenance, and conservative legal posture.
