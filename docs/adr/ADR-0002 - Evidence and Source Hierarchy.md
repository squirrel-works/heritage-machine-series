# ADR-0002 – Evidence and Source Hierarchy  
  
## Title  

Define an explicit evidence hierarchy with primary sources and forbid treating forums as authoritative.  
  
## Context  

The project text specifies strict source ordering: Sears manuals and parts lists first, Emerson documentation, then ANSI/OSHA/ASME, bearing/electrical manufacturers, academic work, and professional woodworking publications, with forums allowed only to surface questions.  
  
## Decision  

- Evidence levels will be explicitly recorded per claim (factory docs, engineering analysis, measurement, community consensus, opinion/experimental).  
- Source priority is:  
  1. Sears manuals and parts lists  
  2. Emerson Electric documentation  
  3. ANSI / OSHA / ASME standards  
  4. Bearing and electrical manufacturer documentation  
  5. Academic publications  
  6. Professional woodworking publications  
  7. Community sources (forums, blogs) only as leads, never primary evidence.  
  
## Consequences  

- Many popular “forum facts” about Craftsman 113 saws cannot be accepted without cross-checking against higher-tier sources.  
- Research and writing will be slower, but the resulting reference is more defensible and less likely to repeat folklore.  
- Every major claim must carry source metadata (type, publication date, confidence, independent verification, and any known conflicts).
