# Identifier Standards

## Purpose

Define stable, human-readable identifiers for objects in the series.

## Principles

- Use fixed, non-recycled identifiers for assets, measurements, claims,
  procedures, chapters, and releases.
- Make identifiers readable and meaningful while remaining compact.

## Examples

- Figures: `FIG-000001`.
- Photographs: `PHOTO-000001`.
- CAD drawings: `CAD-000001`.
- Measurements: `MEAS-000001`.
- Procedures: `PROC-000001`.
- Claims: `CLM-000001`.
- Sources: `SRC-000001`.

## Practice

- Record identifiers in metadata and captions.
- Do not reuse identifiers, even if an object is retired.
- Use identifiers to link documentation, database records, and provenance.

## Notes

Stable identifiers are essential for traceability and knowledge graph
relationships.
