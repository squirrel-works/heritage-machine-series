# Naming Standards

## Purpose

Promote consistent terminology and file naming across the series.

## Terminology

Use the following preferred terms:

- Arbor assembly (avoid "shaft").
- Rip fence (avoid "fence rail").
- Trunnion (avoid "bracket" when referring to saw trunnions).
- Miter slot (avoid "groove").
- Elevation screw (avoid "lift screw").
- Tilt mechanism (avoid "bevel adjustment").
- Flex Drive shaft (avoid "drive cable").

## File Naming

- Use lowercase with hyphens for filenames: `volume-01-restoration.md`.
- Avoid spaces and punctuation in filenames.
- Reflect document scope in the name (e.g., `specifications.md`,
  `lubrication-map.svg`).

## Notes

Consistent naming improves searchability, reduces ambiguity, and supports
long-term maintenance.
