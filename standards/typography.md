# Typography Standards

## Purpose

Define basic typographic conventions for manuscripts and outputs.

## Principles

- Favor readability and clarity over ornament.
- Use heading hierarchies consistently.

## Practice

- Use Markdown headings in a consistent level structure.
- Use tables where appropriate for specifications and tolerances.
- Avoid inline formatting that conflicts with publishing toolchains.

## Notes

Typography is implemented primarily in publishing templates, but source
documents should be structured to support clean output.
