# Citation Standards

## Purpose

Define how sources are cited consistently across volumes.

## Principles

- Prefer primary sources: factory manuals, standards, engineering texts.
- Distinguish clearly between factory guidance, engineering analysis,
  measured data, and community practice.
- Make every substantive technical claim traceable to at least one source.

## Practice

- Use a centralized bibliography (`REFERENCES.bib`, `REFERENCES.md`) for
  full source records.
- In manuscripts, cite sources inline using a consistent format appropriate
  to the publishing toolchain.
- When multiple sources support a claim, prefer the most authoritative and
  note additional supporting sources where useful.

## Source Classification

Each citation should be associated with a source class:

- Factory documentation.
- Standards and technical references.
- Measured observation.
- Independent expert reporting.
- Community discussion.

## Notes

Citation discipline is part of the evidence model. Unsupported claims
should be avoided or explicitly labeled as anecdotal.
