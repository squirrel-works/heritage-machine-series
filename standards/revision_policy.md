# Revision Policy

## Purpose

Define how documents, data, and assets are versioned and revised.

## Principles

- Treat the series as a living reference with documented changes.
- Preserve prior versions rather than overwriting history.

## Practice

- Use semantic versioning for major publications (e.g., `v1.0.0`).
- Record revision history tables in manuscripts and ADRs.
- Create explicit revision records in the database for significant changes.
- Note why a change was made, not only that it occurred.

## Notes

Revision discipline enables readers to understand which guidance applied at
which time and supports long-term maintenance.
