# The Heritage Machine Series

## Engineering Reference Library for Classic Machinery

The Heritage Machine Series is an open engineering reference library
preserving classic machinery through original research, measured data,
CAD, technical documentation, restoration, calibration, modernization,
and evidence-based engineering.

---

## Mission

To produce the most comprehensive, technically rigorous, and legally
defensible engineering references available for classic machinery —
references that preserve not only the machines themselves, but the
engineering knowledge required to maintain, repair, and improve them
for future generations.

This series is an **engineering reference**, not an owner's manual and
not a restoration blog. Every section is designed to be consulted
independently, not read linearly.

## Guiding Principles

1. Primary sources first.
2. Measurements over assumptions.
3. Evidence-based recommendations.
4. Reproducibility.
5. Maintainability.

---

## Evidence Levels

| Level | Description |
| ------- | ------------- |
| A | Factory documentation or manufacturer specification |
| B | Engineering analysis or industry standards |
| C | Verified through hands-on testing or measurement |
| D | Community consensus with multiple independent sources |
| E | Author opinion or experimental technique |
