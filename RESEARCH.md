# Research Standards

Heritage Machine Series

Version: 0.1.0

---

## Purpose

Defines source hierarchy, evidence grading, citation rules, and
verification workflow for all content in The Heritage Machine Series.

---

## Scope

Applies to every factual claim, specification, measurement, and
recommendation in every volume.

---

## Source Hierarchy

Sources are used in the following order of priority:

1. Original Sears owner's manuals
2. Original Sears parts lists and illustrated parts diagrams
3. Emerson Electric engineering documentation (where available)
4. ANSI standards (e.g., ANSI O1.1 Woodworking Machinery Safety)
5. OSHA woodworking machinery guidance
6. ASME references
7. Bearing manufacturer technical handbooks (SKF, NSK, NTN, Timken,
 FAG, and others)
8. Electrical manufacturer documentation
9. Academic publications
10. Professional woodworking publications

Internet forums may be used to identify topics requiring further
investigation. Forum posts are never used as primary or sole evidence.

---

## Evidence Grading

| Level | Label | Description |
| ------- | ------------------ | -------------------------------------------------------------------------- |
| A | Factory | Original manufacturer documentation or specification |
| B | Engineering | Engineering analysis or industry standards |
| C | Measurement | Personally verified through hands-on testing or instrumented measurement |
| D | Community | Multiple independent expert sources |
| E | Experimental | Author opinion or experimental technique |

Every technical recommendation includes its evidence level.

---

## Verification Rules

1. Never repeat internet folklore without verification.
2. Trace every technical claim to one of:
   - Factory documentation
   - Engineering analysis
   - Instrumented measurement
   - Independent verification from multiple experienced restorers
3. If conflicting information exists, identify all positions and explain
 the differences. Do not smooth over conflicts.
4. If evidence is insufficient, state "Not verified" explicitly.
5. Never present an unverified claim as confirmed.

---

## Source Classification

Every source in the bibliography is classified:

| Type | Meaning |
| ------------- | --------------------------------------- |
| Factory | Original manufacturer documentation |
| Standard | ANSI, ASME, OSHA, or equivalent |
| Measurement | Personally verified data |
| Engineering | Derived calculation or analysis |
| Community | Multiple independent expert consensus |
| Historical | Published historical source |

## Unresolved Questions

Unresolved research questions are tracked in TODO.md and in the
database under open_questions.

For each unresolved question, record:

- The question
- Why it is unresolved
- What source would resolve it
- Priority
